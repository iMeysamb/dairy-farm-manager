# Dairy Farm Manager

A complete Android dairy farm management app built with Kotlin + Jetpack Compose.

## Features
- Farm dashboard with KPI cards
- Animal and herd management
- Milk production tracking
- Financial overview
- Alerts and reminders
- Employee management
- Inventory and feed monitoring
- Calendar and tasks

## Requirements
- Android Studio 2024+
- JDK 17
- Android SDK API 34

## Setup
1. Install Android Studio and Android SDK Platform 34.
2. Open this folder in Android Studio.
3. Let Gradle sync.
4. Run on an emulator or physical Android device.

## Build
```bash
./gradlew assembleDebug
```

## APK install
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
